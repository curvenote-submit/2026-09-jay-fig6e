# STEAM-v1 interactive figures

Interactive versions of figures from Qiu, Daza, Welsh *et al.*, *Evolutionary
transfer learning enables organism-wide inference of mammalian enhancer
landscapes*. Each figure is an [anywidget](https://anywidget.dev) that runs
entirely in the browser against a Zarr store of STEAM-v1 predictions — no
kernel, no server.
